## Featured Projects

### 1. [Prescripto](https://github.com/Stv-devl/prescripto-v1)

**AI document intelligence for the construction industry.**

Construction specifications can span hundreds or thousands of pages across multiple technical documents.

Prescripto uses **RAG pipelines, semantic search and LLM agents orchestrated with LangChain and LangGraph** to retrieve relevant clauses, cross-reference documents, identify inconsistencies and assist with drafting technical specifications from source material.

**Architecture & stack**

* React / TypeScript
* Python / FastAPI
* LangChain / LangGraph
* PostgreSQL
* Qdrant
* Mistral
* RAG pipelines
* LLM agents
* Docker / AWS deployment

The project combines software engineering with **12 years of hands-on experience working with construction specifications, quantity takeoffs and project documentation**.

---

### 2. [PlanPilotMCP](https://github.com/Stv-devl/PlanPilotMCP)

**MCP server for AI-assisted CAD workflows with FreeCAD.**

PlanPilotMCP connects AI agents to **FreeCAD through the Model Context Protocol (MCP)**, allowing an agent to interact with CAD tooling and automate drawing workflows.

The project explores how AI agents can interact with professional desktop software and turn natural-language instructions into actions inside an existing engineering tool.

**Focus:** Python, MCP, FreeCAD, AI agents, CAD automation.

This project also connects my software work with my previous experience in the construction industry.

---

### 3. [LoopKit](https://github.com/Stv-devl/LoopKit)

**Agentic development workflows with Claude and Codex.**

An experimental Python project for orchestrating AI coding agents through iterative software development loops.

The workflow is structured around:

`specification → implementation → tests → review → iteration`

with automated feedback loops between specialized agents.

**Focus:** Python, agent orchestration, automated testing, TDD and AI-assisted software engineering.

### 4. Huntyscan

**AI-powered lead generation SaaS for freelancers and consultants.**

Huntyscan discovers relevant opportunities, enriches collected data and uses AI agents to filter and score leads before presenting them through a SaaS dashboard.

The application also includes lead management and a credit-based subscription system.

**Stack:** React, TypeScript, Deno, Supabase, PostgreSQL, OpenAI, Vercel, GitHub Actions.
