## Featured Projects

### 1. [Prescripto](https://github.com/Stv-devl/divbrainers](https://github.com/Stv-devl/prescripto-v1)
Document intelligence for the construction industry.

Writing a CCTP means cross-checking hundreds of pages of technical specs by
hand. Prescripto reads the documents, retrieves the relevant clauses through
semantic search, flags inconsistencies between them, and drafts spec sections
from the source material.

Built with React, FastAPI, PostgreSQL, Qdrant and Mistral, deployed with
Docker on a VPS. Domain expertise comes from 12 years writing these documents
myself.

### 2. Huntyscan
Lead generation SaaS for freelancers and consultants.

Surfaces relevant LinkedIn opportunities, filters and scores them with AI
agents, and serves them through a dashboard with credit-based subscriptions.

React, Next.js, Deno, Supabase, PostgreSQL, OpenAI. CI/CD on Vercel with
GitHub Actions.

### 3. [DivBrainers](https://github.com/Stv-devl/divbrainers)
E-learning platform for technical interview prep: AI-driven mock interviews
with voice, technical quizzes, CV analysis.

Next.js, Prisma, PostgreSQL, Gemini, Vapi.

SyncData enables users to:
